# Portfolio Website

A dynamic, responsive portfolio website that integrates with the GitHub API to display projects in real-time.

## Live Demo

View the live portfolio: [https://popam482.github.io/frontend/](https://popam482.github.io/frontend/)

## Project Overview

This is a multi-page portfolio website built with vanilla HTML, CSS, and JavaScript. It showcases personal information, skills, experience, and GitHub repositories with advanced filtering and sorting capabilities.

## Features

- **Dynamic GitHub Integration**: Fetches and displays repositories from GitHub API
- **Real-time Search and Filtering**: Filter projects by name and programming language
- **Sorting Options**: Sort repositories by last updated, stars, or name
- **Load More Pagination**: Display 6 projects at a time with a "Load More" button
- **Loading State**: Spinner animation while fetching data
- **Error Handling**: User-friendly error messages for network issues, rate limiting, and invalid users
- **Dark Mode**: Toggle between light and dark themes with persistent storage
- **Fully Responsive**: Optimized for mobile, tablet, and desktop screens
- **Smooth Animations**: Reveal animations on scroll and theme transitions

## Pages

- **Home (index.html)**: Profile introduction, passions, activities, milestones, and tech stack
- **Projects (projects.html)**: GitHub repositories with advanced filtering and sorting
- **Skills (skills.html)**: Technical skills and technologies
- **Education and Experience (educationAndExperience.html)**: Education history and work experience

## Technology Stack

- HTML5
- CSS3
- JavaScript
- GitHub API
